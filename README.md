# VELVET — игра для двоих

Полноэкранная SPA-игра для iPhone Safari. Страница не прокручивается; длинный текст карточки прокручивается внутри самой карточки.

## Структура
- `index.html` — экраны приложения.
- `styles.css` — оформление, safe-area и адаптация к экрану.
- `app.js` — логика игры, смена ходов и горизонтальная анимация открытия.
- `data/cards.json` — колода из 257 карточек.
- `config.json` — настройки звуков и игры.
- `sounds/` — пользовательские звуковые эффекты.

## Добавить карточку
Добавь объект в массив `data/cards.json` с уникальным числовым `id`:
```json
{
  "id": 1001,
  "title": "НОВАЯ КАРТОЧКА",
  "text": "Текст задания или вопроса.",
  "color": "Бежевый",
  "category": "Лёгкие",
  "group": "Лёгкие",
  "type": "dare",
  "role": "any",
  "roleLabel": "Универсальная",
  "source": "user"
}
```
Допустимые значения: `type` — `truth` или `dare`; `role` — `boy`, `girl`, `both`, `any`; `group` — `Лёгкие`, `Средние`, `Сложные`, `Дополнения`, `Вопросы`. Для правды укажи `type: "truth"`, `category: "Вопросы"`, `group: "Вопросы"`.

## Звуки
Положи MP3-файлы `spin.mp3` и `win.mp3` в `sounds/`. Пути и громкость меняются в `config.json`. Если файлов нет или Safari не разрешает воспроизведение, используются короткие синтезированные сигналы.

## Контент
Включены 257 карточек: 39 вопросов, 30 лёгких, 30 средних, 29 сложных и 129 дополнительных. Два подтверждённых смысловых повтора удалены (ID 72 и 170). Явные OCR-заголовки и мусорные строки удалялись; неоднозначные слова требуют ручной сверки с фотографиями — догадки не подставлялись.
